既存サイトを更新する場合：ZIPを展開し、index.html・icon.svg・manifest.webmanifestとkanaフォルダ、ライセンス文書をまとめて置いてください。

ひらがな・カタカナ：AnimCJKの筆順SVGを組み込みました。原本はkanaフォルダに同梱しています。
ABC：大文字・小文字と単語の字形見本、手書き練習に対応。ABCの再生は字形のフェード表示で、筆順ではありません。
かず：1〜10の個数を選ぶ問題。
ぬりえ：くまのパーツをタップし、SVG画像を保存できます。
記録：同じ端末の同じブラウザに保存。ブラウザのデータを消すと記録も消えます。
手書きの正誤判定は行いません。
